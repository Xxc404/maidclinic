# 车万女仆：女仆诊所（Maid Clinic）

> Touhou Little Maid 附属 · Minecraft **1.21.1** / NeoForge **21.1.x**
> 一个以**常见病、生命体征与合理用药**为核心的女仆健康管理模组。

![物品预览](docs/preview.png)

---

## 这是什么

《女仆诊所》把“照顾女仆”从喂饭、换装，扩展成一套完整的**健康管理**玩法：

- 女仆会真的生病：感冒、咽炎、胃肠炎、贫血、过敏、失眠、中暑、伤口感染、烫伤、低血糖……
- **病因来自她的游戏内行为**：淋雨、受热、战斗、受伤、劳累、熬夜、挨饿、接触花粉、吃不洁食物……
- 玩家要用**听诊器问诊**，用体温计 / 血压计 / 血氧仪做检查，再**对症**用药；
- 用错药会有代价：病毒感染吃抗生素、退热药过量、抗生素疗程中断，都会带来后果；
- 长期照顾会积累**主仆信赖**，最终可以签订**家庭医生协议**，进入长期健康管理。

> **内容声明**
> 本模组**不含成人内容**。
> 所有医学文本均为科普性质，只用于游戏模拟，**不构成医疗建议**。
> 模组内容遵守中华人民共和国法律法规与公序良俗。

## 核心循环

```
行为与环境（淋雨/受热/战斗/受伤/劳累/熬夜/挨饿/过敏原/不洁饮食）
        │  行为暴露累积
        ▼
发现异常（聊天栏/状态图标/诱因提示）
        │
        ▼
听诊器问诊 ──► 生命体征 + 初步判断 + 诱因 + 建议
        │
        ▼
对症处理（药品 / 护理 / 急救）
        │
        ▼
复诊确认 → 痊愈 → 主仆信赖提升 → 签约家庭医生
```

- **问诊有效期 5 分钟**：超过后需要重新问诊，模拟“先诊断、后用药”。
- **急救类操作**（绷带、敷料、冷敷、补液盐、葡萄糖）不要求先问诊，避免紧急情况下被流程卡住。

## 疾病诱因：女仆的行为决定病因

疾病不再只是“每天掷骰子”，而是由她最近在游戏里**做了什么、处在什么环境**决定。
模组每秒记录一次“行为暴露”（0–100，会随时间衰减），暴露越高越容易发病，
并且决定得的是哪一类病：

| 游戏内行为 | 诱因 | 常见疾病 |
| --- | --- | --- |
| 淋雨、泡水、寒冷群系、钓鱼 | 淋雨受寒 | 病毒性上呼吸道感染、细菌性咽炎 |
| 沙漠/下界等高温环境工作、靠近火源 | 高温暴晒 | 热衰竭、轻度烫伤 |
| 着火、踩进岩浆、被火焰弹命中 | 火焰灼伤 | 轻度烫伤（受伤时直接触发） |
| 战斗、被怪物/玩家攻击 | 战斗受伤 | 伤口感染、缺铁性贫血 |
| 摔伤、仙人掌、甜浆果丛 | 外伤 | 伤口感染 |
| 连续工作、体力透支 | 过度劳累 | 缺铁性贫血、低血糖、失眠 |
| 夜间不睡觉继续活动/工作 | 熬夜缺觉 | 失眠、感冒、高血压（开启慢性病时） |
| 饥饿值过低 | 饥饿与营养不足 | 低血糖、胃肠炎、贫血 |
| 好感度过低、长期战斗/熬夜 | 精神压力 | 失眠、高血压、慢性胃炎 |
| 花丛、蜂箱附近，或割草/采蜜/务农 | 花粉等过敏原 | 过敏性鼻炎 |
| 吃腐肉、生肉、蜘蛛眼、河豚、毒马铃薯、可疑炖菜 | 不洁饮食 | 急性胃肠炎（进食时直接触发） |
| 附近有生病的女仆 | 交叉感染 | 对应的传染病 |
| 以上都没有，纯运气 | 自然发病 | 概率很低（基础值的 25%） |

- 行为暴露超过 60 时，主人会收到一次提醒（同一只女仆 90 秒最多一次），
  例如“淋雨或受凉太久，快让她回屋取暖”；
- 发病时聊天栏会写明诱因，问诊与健康档案里也会显示“诱因：淋雨受寒”；
- 健康档案新增“近期状态：受寒 62｜劳累 35”，方便判断她最近经历了什么；
- 火焰灼伤与不洁饮食是**直接触发**，不做随机判定；其余行为通过暴露值影响概率；
- 关闭 `enableBehaviorTriggers` 可恢复旧版纯随机模型。

| 急救箱（方块） | 物资补给 | 右键领取绷带、补液盐、冷敷贴，有冷却 |

## 疾病与处理要点

| 疾病 | 正确处置 | 常见误区（游戏内会体现） |
| --- | --- | --- |
| 病毒性上呼吸道感染 | 休息、补水、必要时退热 | 用抗生素 → 无效且可能肠道菌群失调 |
| 细菌性咽炎 | 抗生素，完成 3 次疗程 | 症状好转就停药 → 易复发 |
| 急性胃肠炎 | 口服补液盐（补液是关键） | 用抗生素止泻 → 可能加重；完全不补液 → 高概率脱水 |
| 缺铁性贫血 | 铁剂，按疗程 | —— |
| 过敏性鼻炎 | 抗组胺药 | 用抗生素 → 无效 |
| 失眠 | 褪黑素短期辅助 | 长期依赖 → 效果有限 |
| 热衰竭 | 冷敷 + 补液 | 冰水浸泡、酒精擦浴 → 不推荐 |
| 伤口感染 | 绷带清创，必要时抗生素 | 放着不管 → 红肿扩大 |
| 轻度烫伤 | 冷敷，后覆盖敷料 | 涂牙膏/酱油、冰敷 → 加重 |
| 低血糖 | 葡萄糖片 | 意识不清强行喂食 → 危险 |
| 脱水（并发症） | 口服补液盐 | 只喝白水 → 电解质不足 |
| 退热药过量（医源性） | 停药观察 | 继续加量 → 更严重 |

疾病会**自然发展**：不处理时严重程度会随时间上升；部分疾病会自愈，部分会留下并发症，感染的病还可能**传染给附近的女仆**。

> “自限性”不等于“不用管”：急性胃肠炎、热衰竭如果完全不补液/降温，病程结束时有较高概率留下**脱水**；
> 完全没有干预的自愈只给少量主仆信赖，且**不计入“治愈次数”**，签约家庭医生仍需要真正参与治疗。

### 慢性病（可选，默认关闭）

用 `/maidclinic chronic on` 或配置 `enableChronicConditions` 开启。病程 **25–50 分钟**，需要按间隔多次给药，属于“长期管理”：

| 疾病 | 对因处理 | 关键点 |
| --- | --- | --- |
| 高血压 | 降压药 ×4（间隔 90 秒） | 限盐、规律作息、监测血压；剧烈头痛/胸痛/视物模糊需就医 |
| 2型糖尿病 | 降糖药 ×5 | 控制精制糖、监测血糖；用葡萄糖片会加重高血糖 |
| 慢性胃炎 | 抑酸药 ×3 | 规律饮食、少辛辣/浓茶/咖啡；黑便/呕血需就医 |
| 骨质疏松 | 钙+维生素D ×4 | 负重运动、日照；突发腰背剧痛警惕骨折 |

## 女仆初始属性

第一次用听诊器问诊时，会为女仆建立一份“身体档案”。属性分成两类：

| 固定（不可改变） | 说明 |
| --- | --- |
| 血型（ABO + Rh） | 按中国常见分布生成；Rh 阴性约 0.3%。**仅作档案记录，不影响诊断、用药或治疗**（本模组不模拟输血） |
| 身高 | 成年女性 150–172 cm，决定 BMI 的分母 |
| 青霉素过敏 | 约 8%；过敏者不能使用阿莫西林，需改用阿奇霉素 |
| 家族史 | 高血压约 30%、糖尿病约 12%，按系数提高对应慢性病风险 |
| 体质 | 偏弱/普通/强健，影响感染风险与静息心率 |

| 可变（会随照顾变化） | 说明 |
| --- | --- |
| 体重 → BMI | 按中国成人标准分偏瘦/正常/超重/肥胖；影响血压、心率与慢病风险 |
| 运动量 | 低运动 → 骨质疏松、糖尿病风险上升 |
| 盐摄入 | 高盐 → 高血压风险上升 |
| 糖摄入 | 高糖 → 2 型糖尿病风险上升 |
| 睡眠质量 | 差睡眠 → 失眠风险上升 |
| 压力 | 高压力 → 高血压、失眠风险上升 |

- 可变属性每游戏日推进一次：身体健康、主仆信赖 ≥300 时缓慢改善；长期生病时会变差；
- 体重会缓慢向 BMI 22 回归；
- 这些系数只影响“发病权重”和静息读数，不会直接改女仆的战斗属性，避免破坏 TLM 平衡。

## 主仆信赖与家庭医生

| 主仆信赖值 | 等级 |
| --- | --- |
| 0 – 149 | 陌生 |
| 150 – 349 | 熟悉 |
| 350 – 599 | 信赖 |
| 600 – 849 | 默契 |
| 850 – 1000 | 挚友 |

- 问诊、对症治疗、护理、治愈都会提升主仆信赖；完全未干预的自愈只有少量主仆信赖，且不计入治愈次数；
- 用错药、抗生素滥用会降低主仆信赖；
- **主仆信赖 ≥600 且治愈 ≥8 次** 后，使用《家庭医生签约书》即可签约；
- 签约后：发病概率降低 40%，并解锁“长期健康管理”的玩法目标（这是**职业关系**，用于长期健康管理）。

## 安装

1. Minecraft **1.21.1**
2. NeoForge **21.1.x**（开发时对齐 21.1.233）
3. **车万女仆（Touhou Little Maid）1.5.x NeoForge 版**（软依赖：不装也能启动，但本模组的物品没有使用对象）
4. 把 `maidclinic-1.0.0.jar` 放进 `mods/`

> 与《车万女仆》的其它附属（如 maidmarriage）**没有硬冲突**：本模组不使用 mixin，
> 只在“玩家手持本模组物品右键自己女仆”时拦截交互，其余交互完全交还给 TLM。

## 兼容性设计

- **零 mixin**：不注入任何原版/TLM 类，避免版本更新与模组冲突；
- **软依赖**：所有 TLM 相关代码集中在 `com.maidclinic.compat`，未安装 TLM 时该包不会被加载；
- **数据独立**：健康档案保存在世界存档的 `SavedData` 中，不往女仆实体 NBT 里塞私有字段；
- **不改数值**：不修改女仆属性、不覆盖配方、不加世界生成；
- **可配置**：节奏参数集中在 `ClinicSettings`，便于整合包调整。

> 发布前已分别用 NeoForge **21.1.265**（构建工具链）与 **21.1.233**（用户实际运行版本）
> 的 API 各编译一次，并完成资源、语言键、配方与贴图引用的自动校验。

## 医师徽章（女仆饰品）

把徽章装备到女仆的饰品栏后，她会自动治疗 **8 格内**其它女仆（不含自己）：

| 徽章 | 可处理严重度 | 成功率 | 冷却 |
| --- | --- | --- | --- |
| 医师徽章·主任 | 重度及以下 | 95% | 8 秒 |

- 只保留最高级徽章；**等级仍会随医疗经验自动提升**，徽章等级是上限；
- 装备后还会定期给自己和 16 格内的主人提供**生命恢复 + 伤害吸收**，玩家也能直接获得增益；

- 医生自己生病时，成功率额外 -15%；
- 只治疗有“对因治疗”的疾病（普通感冒这类自限性不处理）；
- 不消耗药品，冷却代替耗材；
- 徽章通过 TLM 的饰品栏装备，不会改变原有饰品逻辑；
- **等级会自己升**：治疗成功获得 `1 + 病情严重度` 点经验，4/10/20 经验晋升为 2/3/4 级；徽章等级是上限；
- 生病表情/动作是**软兼容**：装了《女仆可爱动作》就用它的表情触发；没有则尝试《更多动画》的“难受”表情；两者都没装时什么都不显示，也不会报缺前置。

> 玩家与女仆是**主仆关系**：这里的“主仆信赖”是服从、默契与可靠程度，不是恋爱好感度。

## 疾病与工作效率（可开关）

开启后，疾病会通过**移动速度**与**攻击伤害**两项属性影响女仆的工作效率（TLM 的农作、采集、战斗都依赖它们）：

| 状态 | 效率惩罚 |
| --- | --- |
| 轻度疾病 | -10% |
| 中度疾病 | -20% |
| 重度疾病 | -35% |
| 健康（无疾病、无后遗症） | **+20%** |

- 临时惩罚取最严重的一条，不叠加；
- **重度且没有对因治疗**的疾病结束时，会留下与疾病对应的后遗症（合计封顶 -15%）：

| 原发病（重度未治疗） | 后遗症 | 效率惩罚 |
| --- | --- | --- |
| 细菌性咽炎 | 风湿性心脏病 | -4% |
| 高血压 | 靶器官损害 | -4% |
| 2 型糖尿病 | 周围神经病变 | -4% |
| 脱水 | 肾损伤 | -3% |
| 热衰竭 | 热射病后遗 | -4% |
| 伤口感染 | 慢性伤口 | -2% |
| 低血糖 | 认知功能影响 | -3% |
| 退热药过量 | 药物性肝损伤 | -3% |
| 慢性胃炎 | 反复发作 | -2% |
| 骨质疏松 | 骨折风险 | -3% |
- 永久后遗症记录在女仆档案里，换世界/重进游戏仍然存在；
- 关闭开关后，临时惩罚消失、已存在的后遗症**暂停生效**（不会清除）；
- 只改移动速度与攻击伤害，不动 TLM 的任务逻辑与其它属性。

开关方式：

```text
/maidclinic efficiency on|off|default
```

或配置 `enableWorkEfficiency`（默认 `true`）。

## 配置

首次启动后生成 `config/maidclinic-common.toml`：

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `illnessCanKill` | false | 疾病是否可能致死（硬核模式） |
| `criticalDamage` | true | 重度且未治疗时是否持续掉血 |
| `criticalIntervalSeconds` | 15 | 危重掉血间隔（秒） |
| `criticalMinHealth` | 1.0 | 非致死模式下保留的最低生命值 |
| `baseOnsetChance` | 0.001 | 女仆每秒自然发病的基础概率；开启行为诱因时只按 25% 计算（约 66 分钟一次），其余由行为决定 |
| `enableBehaviorTriggers` | true | 疾病是否主要由游戏内行为触发；关闭后恢复旧版纯随机模型 |
| `requireExamBeforeMedicine` | true | 是否必须先问诊才能用处方药 |
| `enableChronicConditions` | false | 是否启用慢性病（高血压、2型糖尿病、慢性胃炎、骨质疏松） |
| `enableWorkEfficiency` | true | 疾病是否降低女仆工作效率（移动/攻击） |
| `enableHealthyBonus` | true | 健康女仆（无疾病、无后遗症）是否获得工作效率加成；随医生经验从 +5% 提升到 +20% |
| `keepSequelaOnDeath` | true | 死亡复活（胶片/祭坛）是否保留完整健康档案（信赖、治愈次数、体质、后遗症等）；可用 `/maidclinic sequela on\|off` 覆盖 |

> **默认不会因疾病死亡**：危重时生命值最多降到 1 点，并反复提示“请立即处理”。
> 想要“病重会死”的硬核体验，有两种方式：
> 1. 在自己的存档里执行 `/maidclinic hardcore on`（只影响自己的女仆，随存档保存，`off` 关闭、`default` 恢复跟随配置）；
>    慢性病同理：`/maidclinic chronic on` 开启、`off` 关闭、`default` 跟随配置；
>    工作效率同理：`/maidclinic efficiency off` 可关闭疾病带来的效率惩罚；
>    复活保留后遗症：`/maidclinic sequela on|off|default`；
> 2. 整合包作者把配置文件里的 `illnessCanKill` 改成 `true`（对所有玩家生效）。

## 已知限制

- 交互只对**自己驯服的女仆**生效（避免误伤他人女仆与 TLM 的驯服流程）；
- 健康档案按 UUID 保存在**当前维度的存档数据**中；女仆被带到其它维度时会新建档案（原档案不会损坏）；
- 行为诱因依赖 TLM 的**任务 id、作息与饥饿值**：如果整合包替换了任务系统，个别行为可能识别不到，
  但淋雨、受热、受伤、饥饿等基础状态仍然有效；
- 所有反馈都是聊天栏/动作栏文本与状态图标，本模组**不做自定义 GUI**（降低兼容性风险）；
- 疾病与药物是压缩后的游戏模型，不能当作真实的诊疗流程；
- 长期未上线的女仆档案会在 7 个游戏日后自动清理。

## 医学依据

详细参考范围、配方与来源见 [`docs/MEDICAL_REFERENCES.md`](docs/MEDICAL_REFERENCES.md)。

摘要：

- 生命体征参考成人静息范围：体温 36.0–37.2℃、心率 60–100 次/分、呼吸 12–20 次/分、血氧 95–100%；
- 发热以腋温 ≥37.3℃ 为界，38.5℃ 以上或有明显不适才用退热药；
- 腹泻/中暑优先口服补液盐（WHO 配方）；
- 抗生素只对细菌感染有效，必须完成疗程；
- 烫伤先用流动冷水冲洗 20 分钟，不冰敷、不涂牙膏/酱油；
- 低血糖按“15–20g 快速碳水、15 分钟复测”处理。
- 慢性病（高血压、2型糖尿病、慢性胃炎、骨质疏松）按指南方向做长期管理；默认关闭，可用 `/maidclinic chronic on` 开启。

**再次声明**：以上内容经过游戏化压缩，仅用于娱乐与科普，不能替代专业医疗建议。
